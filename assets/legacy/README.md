# Cat Room Sprites

Original pixel artwork inspired by the supplied visual and pose references.
These files are not extracted from the watermarked previews or the commercial pack.

- `cat-sprites.png`: 32 x 32 frames, eight columns; idle, walk, sleep, eat, groom, and play rows.
- `room-objects.png`: 64 x 64 cells, six columns; coordinates in `sprite-layout.js`.
- `room-background.png`: 320 x 320 room stage with one consistent isometric projection.
- `sprite-source.js`: editable pixel drawing source used to export the PNGs.

Transparent sprite sheets use nearest-neighbor scaling. The scene includes one cat,
one bed, one food bowl, one water bowl, one litter tray, two plants, one window,
and a framed print and mirror. Empty bowls and dirty litter are alternate frames,
not additional objects in the scene.
